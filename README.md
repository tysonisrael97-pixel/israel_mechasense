MechaSense – Mechatronics Knowledge Assessment System

What it does

MechaSense is a Python-based assessment application designed to evaluate students' knowledge of Mechatronics Engineering.

It presents 15 multiple-choice questions across five engineering topics, including PLC and Automation, Sensors and Instrumentation, Microcontrollers, Electrical Circuits and Electrical Machines.

The application calculates the user's overall score and analyses performance across individual topics.

How to run it

1. Install Python 3.
2. Download the "mechasense.py" file.
3. Open a terminal in the project directory.
4. Run:

"python mechasense.py"

My own twist

I implemented a topic-based knowledge diagnostic system that analyses individual performance across different Mechatronics subjects.

Rather than providing only an overall score, the application identifies the user's strongest and weakest areas and recommends specific topics for further revision.

What I learned

This project helped me apply Python functions, lists, loops, conditional statements, input validation and arithmetic operations in developing a functional application.

It also improved my understanding of how programming can be applied to engineering education and assessment.
